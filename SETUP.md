# ЧАСТЬ 1: Подключить базу данных (Upstash Redis)

Бесплатно, занимает 3 минуты.

## Шаг 1. Регистрация в Upstash

1. Перейти на https://upstash.com
2. Нажать **"Login"** → **"Continue with GitHub"** (быстрее всего)
3. Подтвердить доступ

## Шаг 2. Создать Redis-базу

1. На главной странице Upstash нажать **"Create Database"**
2. **Name**: `qamqor`
3. **Type**: **Regional** (быстрее для одного региона)
4. **Region**: выбрать **eu-central-1 (Frankfurt)** — ближайший к Казахстану
5. **Plan**: **Free** (10 000 команд/день — нам с головой хватит)
6. Нажать **"Create"**

## Шаг 3. Скопировать REST URL и Token

На странице базы найти секцию **"REST API"** (или вкладка "REST"):

- Скопировать **UPSTASH_REDIS_REST_URL** (выглядит как `https://eu1-xxx-12345.upstash.io`)
- Скопировать **UPSTASH_REDIS_REST_TOKEN** (длинная строка)

## Шаг 4. Добавить в Vercel

1. Зайти в свой проект на vercel.com → **Settings** → **Environment Variables**
2. Добавить **три новые переменные**:

| Key | Value |
|---|---|
| `UPSTASH_REDIS_REST_URL` | (URL из Upstash) |
| `UPSTASH_REDIS_REST_TOKEN` | (Token из Upstash) |
| `CRON_SECRET` | любая случайная длинная строка, например `super_secret_random_string_123abc` |

3. Нажать **Save** после каждой

# ЧАСТЬ 4: Проверка

## Тест /start

1. Откройте Telegram
2. Найдите вашего бота (по username, например `@qamqor_bot`)
3. Отправьте **/start**
4. Должно прийти приветствие с **кнопкой "🚀 Открыть Qamqor"**
5. Тапнуть на кнопку → Mini App откроется

## Тест push-уведомлений

Cron работает раз в день в 04:00 UTC (10:00 Астана). Чтобы протестировать **прямо сейчас**:

1. Откройте в браузере:
```
https://ваш-домен.vercel.app/api/cron/daily
```

⚠️ Если включена защита через `CRON_SECRET` — этот URL вернёт `Unauthorized`. Для теста временно уберите переменную `CRON_SECRET` в Vercel, запустите cron, потом верните обратно.

2. В ответе JSON будет:
```json
{ "sent": 1, "failed": 0, "total": 1, ... }
```

3. В Telegram должно прийти сообщение с пушем + кнопкой открыть приложение.

# Что менять дальше

## Изменить время push-уведомлений

В файле `vercel.json` строка:
```json
"schedule": "0 4 * * *"
```

Формат: `минута час день_месяца месяц день_недели` (UTC)

Примеры:
- `0 3 * * *` — 03:00 UTC = 09:00 Астана
- `0 12 * * *` — 12:00 UTC = 18:00 Астана
- `30 5 * * *` — 05:30 UTC = 11:30 Астана

После изменения: `git push` → дождаться деплоя.

⚠️ Vercel Hobby (бесплатный) разрешает только **раз в день**. Чаще — Pro плана.

## Изменить тексты push-уведомлений

В файле `app/api/cron/daily/route.js` в начале — массив `DAILY_MESSAGES`. Меняйте title и body как угодно. Сообщения чередуются по дню месяца.

## Добавить логирование

Все вызовы видны в Vercel:
- **Dashboard** → ваш проект → **Logs** или **Runtime Logs**
- Cron-вызовы — там же, фильтр по `/api/cron`

# Если что-то сломалось

## Бот молчит на /start

1. Проверьте webhook: откройте `https://ваш-домен.vercel.app/api/setup` — должна быть страница с "Webhook OK"
2. Проверьте Vercel Logs (Runtime Logs) — есть ли вызовы `/api/telegram/webhook`?
3. Если нет вызовов — webhook не установлен. Запустите `/api/setup` ещё раз.

## Pushes не приходят

1. Откройте `/api/cron/daily` вручную (временно убрав `CRON_SECRET`) — посмотрите ответ
2. Если `total: 0` — пользователи не записались в БД. Проверьте Upstash переменные.
3. Если `sent: 0, failed: N` — проблема с Bot API. Проверьте `TELEGRAM_BOT_TOKEN`.

## "Authorization required" на /api/cron/daily

Это нормальная защита. Для теста временно уберите `CRON_SECRET` в Vercel → передеплоится → попробуйте → верните обратно.

## Сборка в Vercel падает

Скорее всего из-за отсутствующих env vars. Все обязательные перечислены в начале этого файла.
