# Как добавить новую норму вручную (через админку)

1. Зайти на `/api/admin/legal?key=...`
2. В блоке **"➕ Добавить норму"** заполнить поля:
   - **ID** — уникальный идентификатор латиницей (например `tk_otpusk_uchebnyy`)
   - **Источник** — например "Трудовой кодекс РК"
   - **Статьи** — например "Статья 90"
   - **Тема** — короткое название
   - **Ключевые слова** — через пробел (для улучшения поиска)
   - **Содержание** — полный текст нормы (100-300 слов)
3. Нажать **"Добавить норму"**
4. Страница обновится, новая норма появится в списке. Через несколько минут (кэш) юрист начнёт её использовать в ответах.

**Официальный источник:** https://adilet.zan.kz — там полные тексты всех кодексов и законов РК. Найдите нужную статью, прочитайте, переформулируйте кратко и понятно (100-300 слов), сохраните как новую норму через админку.

# Как удалить норму

В админ-странице в списке справа от каждой нормы есть красная кнопка **×**. Нажать → подтвердить. Норма исчезнет из базы. Кэш обновится за несколько минут.

# Структура одной нормы (для JSON-импорта)

```json
{
  "id": "уникальный_id_латиницей",
  "source": "Название кодекса/закона РК",
  "articles": "Статья X или Статьи X-Y",
  "topic": "Короткое описание темы",
  "keywords": "ключевые слова через пробел",
  "content": "Полный текст нормы 100-300 слов..."
}
```

JSON-импорт принимает **массив** таких объектов, например:

```json
[
  { "id": "...", "source": "...", ... },
  { "id": "...", "source": "...", ... }
]
```

# Если что-то не работает

### Юрист не использует новые нормы

Кэш эмбеддингов держится 5 минут. Подождите 5 минут после изменений или перезапустите страницу.

### "Cannot read property 'embedding' of undefined" в логах

Норма добавлена без эмбеддинга. Удалите её и добавьте заново — возможно был временный сбой Gemini API.

### Bulk-import показывает "added: 0, skipped: 30"

Все 30 норм уже есть в базе (по id). Это нормально, просто значит вы уже импортировали ранее.

### "Невалидный JSON" при импорте

Проверьте что вставили корректный JSON-массив. Можно проверить на https://jsonlint.com.

# Лимиты Gemini Embedding

Каждая добавляемая норма = 1 запрос к Gemini Embedding API. Лимит — 1500/день.

Если будете добавлять много за раз — учитывайте этот лимит. Bulk-import из 30 норм = 30 запросов, не критично.

Для серьёзного расширения базы (500+ норм) — лучше делать порциями по 50-100 в день.
