# Что нужно сделать после деплоя

## Шаг 1. Добавить новую переменную ADMIN_PASSWORD в Vercel

В Vercel → ваш проект → **Settings** → **Environment Variables**, добавить:

| Key | Value |
|---|---|
| `ADMIN_PASSWORD` | любая длинная строка, например `qamqor_admin_x7k2pq9w` |

**Save**. Дальше — Deployments → последний → **Redeploy** (или просто `git push`).

## Шаг 2. Залить обновлённый код

Распакуйте новый zip поверх старой папки. Затем:

```bash
cd qamqor
git add .
git commit -m "rate limit + analytics + lawyer RAG"
git push
```

Подождите 2 минуты пока Vercel задеплоит.

## Шаг 3. Загрузить базу знаний юриста (один раз)

После того как новый код задеплоился — откройте в браузере:

```
https://ваш-домен.vercel.app/api/admin/seed-legal?key=ВАШ_ADMIN_PASSWORD
```

Откроется страница, которая:
1. Прогонит все 30 chunks через Gemini Embedding API
2. Сохранит эмбеддинги в Upstash Redis
3. Покажет таблицу со списком всех норм в базе

⏱ Занимает ~30 секунд. Должно показать **30 successfully**.

После этого юрист начнёт отвечать с опорой на эти нормы и **показывать источники под каждым ответом** (Трудовой кодекс, статья X — Тема).

## Шаг 4. Открыть аналитический дашборд

```
https://ваш-домен.vercel.app/api/admin/dashboard?key=ВАШ_ADMIN_PASSWORD
```

Сразу — нули. По мере использования приложения цифры будут расти. Что показывается:
- Всего пользователей, DAU за сегодня
- Общее количество сообщений и чек-инов
- DAU-диаграмма за 7 дней
- Диаграмма сообщений по дням
- Распределение по агентам (доктор/юрист/финансист)
- Кликов "Подписка" + конверсия

**Сохраните ссылку в закладки** — это ваш главный инструмент для отслеживания роста.

# Архитектура новых фич

```
ЮРИСТ С RAG:
  Запрос пользователя
       ↓
  Gemini Embedding (text-embedding-004) → вектор запроса
       ↓
  Загружаем 30 chunks с эмбеддингами из Upstash Redis
       ↓
  Cosine similarity → топ-4 chunks
       ↓
  Подкладываем в systemPrompt → отправляем в Gemini 2.5 Flash
       ↓
  Ответ + список источников возвращаем клиенту
       ↓
  Под сообщением рисуем плашки "Источники"

RATE LIMIT:
  Каждый запрос → INCR в Redis с TTL 60с (per minute)
                → INCR в Redis с TTL 86400с (per day)
  Если >лимит → 429 ответ, клиент показывает ошибку

АНАЛИТИКА:
  События с клиента → /api/analytics/track (с verified initData)
  События с сервера → trackEvent() в /api/chat
       ↓
  Записывается в Redis:
    - stats:total:{event}  (вся история)
    - stats:day:{event}:{date}  (по дням, TTL 90д)
    - stats:dau:{date}  (set активных пользователей, TTL 90д)
       ↓
  Dashboard читает и показывает
```

# Если что-то не работает

### Юрист не показывает источники
1. Не запущен seed: откройте `/api/admin/seed-legal?key=...`
2. Не настроен Upstash: проверьте env vars `UPSTASH_REDIS_REST_URL` и `_TOKEN`
3. Низкая similarity (<0.5): пользователь спросил что-то не из базы — это нормально, агент ответит без источников

### Rate limit срабатывает сразу
- В `lib/ratelimit.js` увеличьте `perMinute` и `perDay` для triala

### Дашборд пустой
- Если только что задеплоили — это нормально, надо чтобы кто-то попользовался
- Если приложение работает, а на дашборде 0 — проверьте что `UPSTASH_*` env vars одинаковые

### "Unauthorized" на /api/admin/*
- Проверьте `ADMIN_PASSWORD` в Vercel env vars
- В URL после `?key=` подставляется ИМЕННО эта строка

### Seed не работает (Embedding error)
- Лимит Gemini Embedding API исчерпан — подождите час или попробуйте завтра
- 30 запросов выполняются с задержкой 50мс — не должно упереться в лимит

# Лимиты и нагрузка

| Что | Лимит | Хватит на |
|---|---|---|
| Gemini Chat | 1500 req/день | ~50 активных юзеров/день при 30 сообщений каждый |
| Gemini Embedding | 1500 req/день | seed (30) + ~1400 запросов юристу/день |
| Upstash Redis | 10 000 команд/день | ~500 активных юзеров/день |
| Vercel Functions | 100 GB-hours/мес | да, с запасом |

⚠️ **Узкое место — Gemini Embedding**. Каждый запрос к юристу = 1 embedding на запрос + 1 chat. При 100 активных юзерах в день, делающих по 15 запросов юристу — 1500 embeddings, на грани.

При росте — упрётесь сюда. Решения:
- Кэшировать эмбеддинги популярных вопросов в Redis (с TTL)
- Перейти на платный тариф Gemini (нужна карта)
- Использовать локальные эмбеддинги (sentence-transformers через отдельный сервис)
